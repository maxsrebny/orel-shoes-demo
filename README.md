# Прототип приложения салона обуви (Вариант 2 «Клуб салона»)

Кликабельный прототип Telegram Mini App на дизайн-системе `design/` (день A «Галерея», ночь из B). Без сервера: данные вымышленные, состояние хранится в браузере, «Сбросить демо» в Профиле.

## Открыть
- В браузере: `python3 -m http.server 8765` в этой папке → http://localhost:8765 (смотреть при ширине телефона). Двойной клик по `index.html` тоже работает, кроме шрифтов без интернета.
- В Telegram: https://t.me/orel_shoes_demo_bot?startapp (настройка бота — `../telegram/botfather.md`).
- Опубликованная копия: см. README проекта.

## Роли
- **Покупательница** (по умолчанию): Каталог, Новинки, Клуб, Профиль, Сообщения (колокольчик).
- **Персонал**: Профиль → Для персонала → PIN `1111`: Сегодня (брони и запросы), Клиенты (поиск, QR, начисление, привязка чека), Наличие (остатки из МойСклада, «Не было размера», «Поступление +1»), Ещё (упущенный спрос, выход).
- **Владелец**: Ещё → Кабинет владельца: цифры недели, выручка по дням, упущенный спрос, клуб, дайджест с кнопкой «Одобрить рассылку».

## Демо-сценарий на встрече, 5 минут
1. Каталог → лодочки с острым носом → размер 38 → «Отложить на примерку» → подтвердить. В Клубе появилась бронь «Ждёт ответа», в Сообщениях — уведомление.
2. Профиль → Для персонала → PIN 1111 → Сегодня → у брони Анны «Подтвердить». Вернуться в Профиль (Ещё → Выйти): в Клубе статус «Отложено», в Сообщениях — «Пара ждёт вас до завтра, 20:00».
3. Персонал → Сегодня → «Куплена»: бонусы начислены, пара списана с остатка, в Клубе новая строка истории.
4. Персонал → Наличие → любая модель → размер → «Не было размера»; затем «Поступление +1» для размера из листа ожидания — клиент получает сообщение «Появился ваш размер».
5. Ещё → Кабинет владельца → «Одобрить рассылку».
6. Профиль → тема «Ночь» (или «Как в Telegram»), «Сбросить демо» перед следующим показом.

## Что в прототипе условно
- Остатки «из МойСклада», бонусы «через Бонус Плюс» и сообщения бота имитируются внутри страницы; в системе они приходят из интеграций.
- Начисление по чеку и поступления в режиме персонала — демо-кнопки: в системе приход делается в МойСкладе, бонусы считает «Бонус Плюс» по чеку Эвотора.
- Сканер QR работает только в Telegram на телефоне.
- Фото — из открытых публикаций салона (Instagram, 2ГИС), только для внутреннего показа; названия моделей, цены, клиенты и цифры вымышленные.

## Файлы
`index.html` — каркас; `styles.css` — раскладка поверх дизайн-системы; `tokens.css`, `components.css` — копии из `design/` (источник истины там); `data.js` — демо-данные; `app.js` — роутер, экраны, действия, Telegram SDK; `vendor/` — SDK Telegram и QR-библиотека; `assets/` — фото.
